# Definition of Done

Every task is finished only when all of these are true:

- Works in the light, dark and holiday themes.
- Works left-to-right and right-to-left (logical classes: `ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`).
- Responsive at 360, 768, 1024 and 1440 px wide.
- Usable with the keyboard, with a visible focus ring.
- No errors in the browser console.
- `npm run lint`, `npm run typecheck`, `npm run test` and `npm run build` all pass.
- Every new package, font or icon is recorded by running `npm run licenses`.
- Committed to Git with a clear message.
